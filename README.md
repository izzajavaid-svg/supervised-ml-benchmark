# Supervised ML Benchmark — Telco Customer Churn

Trains and compares 7 model families (11 configurations total) on a customer-churn
classification task, and selects a final model based on validation performance,
confirmed once on a held-out test set.

## 1. Setup

```bash
python3 -m venv venv
source venv/bin/activate        # Windows: venv\Scripts\activate

pip install pandas numpy scikit-learn matplotlib xgboost jupyter tabulate
```

(`tabulate` is only needed because the notebook renders `observations.md` tables with
`DataFrame.to_markdown()`.)

## 2. Data

The notebook loads the [IBM Telco Customer Churn dataset](https://github.com/IBM/telco-customer-churn-on-icp4d)
(7,043 rows, 21 columns) automatically:

- If `data/Telco-Customer-Churn.csv` exists locally, it's used directly (offline-friendly,
  fully reproducible).
- Otherwise, it's downloaded from the public GitHub URL at runtime.

To run fully offline, download the CSV yourself and place it at `data/Telco-Customer-Churn.csv`
before opening the notebook:

```
https://raw.githubusercontent.com/IBM/telco-customer-churn-on-icp4d/master/data/Telco-Customer-Churn.csv
```

## 3. Running

Open `supervised_ml_benchmark.ipynb` in VS Code (or Jupyter Lab/Notebook) and run
**Kernel → Restart & Run All**. Cells are strictly linear — nothing depends on a
variable defined later in the notebook, so a top-to-bottom run always completes without
`NameError`s.

Runtime: a few seconds to ~1 minute depending on your machine (Random Forest and the two
SVM configurations are the slowest steps).

## 4. What gets produced

Running the notebook creates a `results/` folder alongside it:

```
results/
├── validation_results.csv          # all 11 models × accuracy/precision/recall/F1/ROC-AUC/timing
├── training_results.csv            # same models scored on their own training data
├── final_test_results.csv          # the one selected model, evaluated once on the test set
├── accuracy_comparison.png
├── classification_metrics.png      # precision/recall/F1 grouped bar chart
├── timing_comparison.png           # training + inference time, side by side
├── roc_curves_all_models.png
├── final_test_confusion_matrix.png
├── final_test_roc_curve.png
└── confusion_matrices/
    └── confusion_matrix_<model>.png   # one per model, on the validation set
```

It also (re)writes `observations.md` in the project root — that file is generated
**by the notebook itself** from the live results, so it can never drift out of sync
with the numbers actually produced by a given run.

## 6. Models trained

| Model | Variants |
|---|---|
| Logistic Regression | 1 configuration |
| K-Nearest Neighbors | K=5, K=15 |
| Decision Tree | depth=1 (underfit), depth=5 (shallow), unrestricted (deep, overfit) |
| Random Forest | 200 trees |
| Gradient Boosting | scikit-learn `GradientBoostingClassifier` |
| XGBoost | `xgboost.XGBClassifier` |
| SVM (RBF kernel) | without feature scaling, with feature scaling |

All 11 configurations share one `train_test_split` (60/20/20, stratified, seed=42) and
one `ColumnTransformer`-based preprocessing pipeline (median/most-frequent imputation,
one-hot encoding, `StandardScaler` for scale-sensitive models) — see Section 3 of the
notebook for the full rationale behind each preprocessing decision.
